Logos monocromos de las tecnologías (assets/icons/<nombre>.svg).

Fuente: Simple Icons (https://simpleicons.org), licencia CC0 1.0.
Se usan como máscara CSS (.chip__logo) y se pintan con currentColor, así
respetan el acento y el tema claro/oscuro. Para agregar uno: descarga el SVG
monocromo aquí y pon `icon: '<nombre>'` en la habilidad en js/data.js.
